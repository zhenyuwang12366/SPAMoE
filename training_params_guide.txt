Key training CLI parameters
=============================

Basic runtime
-------------
- `--mode` (default `train`): train, inference, or encoder-only pretraining.
- `--data_dir`: dataset root; falls back to config default if omitted.
- `--family`: subset / geology family (`vel`, `fault`, `style`, `all`, or fine-grained keys such as `curve_vel_a`).
- `--batch_size` / `--test_batch_size`: train vs eval batch sizes; test batch falls back to config when unset.
- `--epochs`: total epochs (interacts with schedulers and early stopping).
- `--num_workers`: DataLoader workers; tune for IO vs CPU.
- `--seed`: RNG seed for reproducibility.
- `--resume_path`: checkpoint to resume optimizer + model state.
- `--encoder_path`: load/freeze a standalone encoder checkpoint.

Data & preprocessing
----------------------
- `--n_train_samples` / `--n_test_samples`: cap dataset size for smoke tests.
- `--channel_dim`: which tensor axis counts channels together with `--concat_channels`.
- `--concat_channels` / `--no_concat_channels`: stack receiver traces along width vs keep separate channels (must match model input).
- `--k`: `LogTransform` scaling constant affecting normalized dynamic range.

Optimizer & gradients
---------------------
- `--learning_rate`: base LR; scale when using grad accumulation or multi-GPU effective batch.
- `--weight_decay`: AdamW L2-style decay.
- `--accum_steps`: gradient accumulation to emulate large batches on limited VRAM.
- `--use_amp`: PyTorch autocast for forward/backward.
- `--mixed_precision`: optional separate toggle for inference mixed precision.
- `--use_onecycle` / `--disable_onecycle`: OneCycle LR policy vs other schedulers.

LR schedule
-----------
- `--lr_warmup_epochs`, `--lr_warmup_factor`, `--lr_warmup_method`: warmup schedule.
- `--lr_scheduler_type`: `cos_restart`, `cos`, or `multistep`.
- `--milestones`, `--scheduler_gamma`: MultiStepLR knobs.
- `--lr_cosine_tmax_epochs`, `--lr_cosine_eta_min`: cosine annealing period / floor LR.
- `--lr_cosine_restart_t0_epochs`, `--lr_cosine_restart_t_mult`: cosine-restart parameters.

Early stopping & monitoring
----------------------------
- `--early_stop`: enable early stopping.
- `--early_stop_patience`, `--early_stop_min_delta`, `--early_stop_warmup_epochs`: patience, minimum gain, warmup before monitoring.
- `--eval_interval`: validation frequency (epochs).
- `--profile_timing`: print timing breakdown for hotspots.

MoE structure
--------------
- `--use_moe`: load frozen experts and train router only.
- `--use_experts_path`: directory with per-expert `.pt` weights (required when `--use_moe`).
- `--choose_experts`: expert indices (FNO/WNO/MNO/LNO mapping follows `parser_utils`).
- `--top_k`: number of experts activated per forward pass.
- `--use_encoder` / `--disable_encoder`: toggle encoder; when disabled raw inputs feed MoE (channel counts must match).
- `--moe_mode`: `standard` vs `velocity_type` fusion semantics.
- `--router_type`, `--router_hidden_dim`: router architecture (`adamv` needs matching callbacks).
- `--fusion_type`, `--s_processor_type`, `--w_processor_type`: fusion inside MoE (linear, attention, mean, sum, ...).
- `--enable_noisy_gating` / `--disable_noisy_gating`: noisy logits for load balancing.
- `--beta`: strong vs weak expert mixing coefficient.
- `--is_specific`: enable fine-grained naming / filtering (curve/flat/style splits).
- `--is_classifier`: enable grouped-expert (GMoE-style) classifier routing.
- `--v_type_num`: number of velocity-type logits for the router head.
- `--use_gpu_proxy`: memory proxy for large expert pools.

Expert hyperparameters
----------------------
- `--hidden_channels`: trunk width shared by experts.
- `--FNO_*`, `--WNO_*`, `--MNO_*`, `--LNO_*`: per-expert structural knobs (modes, layers, wavelets, ...).
- `--GeoFNO_*`: geometric FNO settings when enabled.
- `--wavelet_type`, `--dtcwt_type`, `--WNO_pad_mode`, ...: wavelet expert details.
- `--MNO_scale_factors`: descending list of relative resolutions for multiscale experts.

Experiment utilities
----------------------
- `--use_wandb`: log metrics/plots to Weights & Biases.
- `--vis_freq`: how often to dump qualitative predictions / spectra.
- `--report_every`: stdout cadence for external schedulers (parsed in training script).

Practical tips
--------------
1. Lock structural knobs first (`--family`, `--choose_experts`, `--top_k`, `--use_encoder`, `--use_moe`), then tune LR/schedule.
2. When OOM: shrink `--batch_size`, increase `--accum_steps`, reduce `--top_k`, or enable `--use_gpu_proxy`.
3. For reproducible papers: fix `--seed`, archive `--encoder_path` / `--resume_path`, and log the full CLI in experiment notes.
